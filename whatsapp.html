  1. Clique em Preparar conexão — cria a instância e cadastra o webhook.
  2. Clique em Gerar QR Code.
  3. No celular do DAM: WhatsApp → Configurações → Aparelhos conectados → Conectar aparelho.
  4. Aponte a câmera para o QR Code desta tela.
  5. O status vira conectado sozinho. Mande uma mensagem de outro celular para testar.
